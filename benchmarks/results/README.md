# Measured benchmark results (frozen)

This directory holds **measured, immutable** validation results — the output
of reproducible commands, never hand-edited numbers. Each result file:

- carries a `provenance` block (git commit, input SHA-256, pipeline version,
  config hash, run timestamp, report hash);
- is (re)generated by a single committed command;
- is referenced from the "Ölçülen ve dondurulan sonuçlar" table in
  `docs/validation.md`;
- is enforced by a contract test under `tests/` where applicable.

| File | Gate | Reproduction command |
|------|------|----------------------|
| `similarity_sensitivity_v1.json` | 7 (Earth-similarity weight sensitivity) | `python scripts/validation/run_similarity_sensitivity.py` |

When a new measured run is frozen here, add a row to both this table and the
one in `docs/validation.md`. A file that is not reproducible by a committed
command must not be added.
