# AstroTransit Cycle 6 Discovery Portfolio Evidence Package

This dataset contains data products, MCMC fits, figures, configuration files, and verification reports for 10 pure novelty exoplanet candidates.

## Package Architecture

AstroTransit_Zenodo_Cycle6_Discovery_Portfolio_v1/
├── .zenodo.json           # Zenodo REST API Metadata
├── DISCOVERY_NOTE.md      # Detailed scientific discovery note
├── README.md              # Navigation guide
├── SHA256SUMS.txt         # SHA-256 integrity checksums
├── manifest.json          # Complete file manifest
├── configs/               # Pipeline TOML configurations used
├── environment/           # Python version & pip freeze reproducibility files
├── data_products/         # CSV, JSON parameter distributions, and fits
├── figures/               # Publication-grade light curves & diagnostic plots
└── reports/               # Vetting, crosscheck, and FPP verification reports

## Citation
