# AstroTransit Cycle 6 Verified Discovery Portfolio (v2 Clean Release)

This package contains data products, MCMC fits, and vetting reports for verified Class A Non-TOI candidates.

## Package Structure
- /data_products/ : Contains verified_classA_discovery_portfolio.csv and MCMC JSON fits.
- /figures/        : 300 DPI phase-folded plots for Class A targets.
- /reports/        : FPP reports and crosscheck notes.
- /environment/    : Python & library version freeze for reproducibility.
