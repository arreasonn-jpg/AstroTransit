# AstroTransit Prescreened Candidate Watchlist (v1 Release)

This package contains pre-processed light curves, MCMC posterior parameter fits, and diagnostic vetting reports for unconfirmed TESS candidates.

## Directory Structure
- /data_products/ : prescreened_candidate_watchlist.csv and MCMC JSON fits.
- /figures/        : Phase-folded light curve plots.
- /reports/        : Heuristic FPP diagnostic json reports.
- /environment/    : Reproducibility environment files.
