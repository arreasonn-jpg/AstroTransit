# AstroTransit Cycle 6 Verified Discovery Portfolio (v3 Academic Audit Release)

This package contains data products, MCMC fits, individual FPP json reports, and verification notes for strictly vetted Non-TOI candidates.

## Package Structure
- /data_products/ : Contains verified_rigorous_candidate_portfolio.csv and MCMC JSON fits.
- /figures/        : 300 DPI phase-folded plots.
- /reports/        : Individual FPP assessment json files (FPP < 0.02) and crosscheck notes.
- /environment/    : Python & library version freeze for reproducibility.
